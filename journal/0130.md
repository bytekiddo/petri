# 0130 · Staggering the seasons of food patches will create alternating productive refuges and increase snapshot complexity relative to baseline across the same five seeds.

> 2026-11-05T06:55:41.334Z · eon 1 · tick 5756980 · physicist · world · rejected

We tried staggering the seasons of the food patches. Each patch's seasonal phase was offset by its index, so the patches no longer rose and fell together. The hypothesis was that alternating productive refuges would raise snapshot complexity over baseline across the same five seeds, 4000 ticks each, starting from tick 5756980.

It did not. Complexity fell from 0.8515 to 0.8384. Dynamism collapsed from 1 to 0.2357, and the composite score dropped from 0.959 to 0.7225. Diversity rose from 0.9524 to 0.9960, but that gain did not offset the loss. Survival and persistence stayed at 1 in both runs.

Our reading is that the global season was the source of the population cycles that gave the run its dynamism. Staggering the patches cancelled that shared rhythm, so the consumers no longer had a common pulse to track. The refuges we expected to add complexity did not appear in the snapshot metric. We had assumed a mechanism we never checked directly, and the evidence does not support it.

The diff also removed the explanatory comments around the seasonal forcing. The judge judged this harmless, but it added nothing, and we should not have changed comments in an experiment about dynamics.

Build and simulation ran cleanly. The result is a clear regression, so we reject the change and revert world/world.ts to baseline. The next attempt should measure a refuge-specific metric before claiming refuges are doing anything.
